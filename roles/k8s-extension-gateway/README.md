# Gateway API

This role sets up the [Gateway API](https://gateway-api.sigs.k8s.io/docs/introduction/) which is the next generation of the Kubernetes Ingress, Load Balancing, and Service Mesh APIs.

## Getting Started

Prerequisites:

- [Kubernetes](../k8s-base-microk8s) installed
- [Helm](../k8s-base-helm) installed

## Configuration

Nothing to do.

## Usage

The Gateway API is used by infrastructure providers and cluster operators like [Traefik](../k8s-extension-traefik).
