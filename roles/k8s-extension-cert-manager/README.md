# Cert Manager

This role sets up [Cert Manager](https://cert-manager.io/docs/), a certificate manager for the Kubernetes (k8s) instance.

## Getting Started

PrerequisiteS:

- [Microk8s (Kubernetes)](../k8s-base-microk8s) installed
- [Helm](../k8s-base-helm) installed

## Usage

To use the cert manager, [read this guide](https://cert-manager.io/docs/tutorials/acme/nginx-ingress/).
